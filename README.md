LLM-Generated Text Detection Project


![Hugging Face](https://img.shields.io/badge/%F0%9F%A4% hugging%20face-datasets-yellow)


This project provides a comprehensive framework for detecting text generated by Large Language Models (LLMs). It performs a comparative analysis of different detection techniques on the HC3 (Human-ChatGPT Comparison Corpus) dataset and includes a standalone script for real-time inference on new text.

✨ Features

Data Loading & Preprocessing: Downloads and prepares a large, balanced subset of the HC3 dataset from Hugging Face.

Data Visualization: Generates insightful plots to understand the characteristics of human-written vs. AI-generated text, including text length distributions and word clouds.

Multiple Detection Strategies: Implements and evaluates three distinct detection methods:

TF-IDF + Logistic Regression: A classic machine learning baseline using sparse text features.

Statistical & Semantic Features + XGBoost: A more advanced approach using linguistic complexity, perplexity, and other statistical markers.

Fine-tuned RoBERTa: A state-of-the-art deep learning method using a transformer-based model to capture deep semantic patterns.

Ensemble Method: Combines the predictions of the three models using a majority vote mechanism for potentially improved accuracy and robustness.

Comprehensive Evaluation:

Calculates and reports F1-score, precision, and recall for each individual strategy and the final ensemble model.

Saves a detailed Excel report (evaluation_results.xlsx) with the ground truth and predictions for every text sample in the test set, perfect for error analysis.

Real-time Inference: Includes a standalone inference.py script to analyze new, unseen text using the trained models.

Modular Codebase: The project is structured into separate, well-documented Python files for clarity, maintainability, and reusability.

📂 Project Structure

.

🚀 Setup and Installation

Clone the repository (or save all files to a single directory).

Create and activate a Python virtual environment (recommended):

python -m venv venv
source venv/bin/activate  # On Windows, use `venv\Scripts\activate`


Install the required dependencies:
You may need to install openpyxl for saving Excel files.

pip install -r requirements.txt


Download NLTK data (for statistical features):
Run Python and enter the following commands to download the necessary package:

import nltk
nltk.download('punkt')


🏃 How to Run the Project

Step 1: Train All Models

Run the main script from your terminal. This will execute the entire training and evaluation pipeline.

python main.py


This script will:

Download and preprocess the HC3 dataset.

Generate and save data visualizations in the plots/ directory.

Engineer features for the machine learning models.

Train all three detection models and save them to the models/ directory.

Evaluate each model on the test set.

Perform an ensemble evaluation using a voting mechanism.

Print a final performance report to the console.

Save the detailed test results to evaluation_results.xlsx.

Step 2: Analyze New Text

After the training is complete, you can use the inference.py script to classify any new text.

python inference.py


The script will first analyze two example sentences and then prompt you to enter your own text for real-time detection.

📊 About the Models

Logistic Regression: A simple yet effective linear model that works on TF-IDF features to find patterns in word usage.

XGBoost: A powerful gradient-boosting model that uses statistical and semantic features like text length, perplexity, and linguistic complexity to make predictions.

RoBERTa: A large language model from the transformer family, fine-tuned on the specific task of distinguishing between human and AI text. It is designed to learn deep semantic and contextual patterns.

This project provides a robust foundation for further research and experimentation in the field of LLM-generated text detection.
