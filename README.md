LLM-Generated Text Detection Project
This project provides a comprehensive framework for detecting text generated by Large Language Models (LLMs). It performs a comparative analysis of different detection techniques on the HC3 (Human-ChatGPT Comparison Corpus) dataset.

Features
Data Loading & Preprocessing: Downloads and prepares the HC3 dataset from Hugging Face.

Data Visualization: Generates plots to understand the characteristics of human-written vs. AI-generated text, including text length distribution and word clouds.

Multiple Detection Strategies: Implements and evaluates three distinct detection methods:

TF-IDF + Logistic Regression: A classic machine learning baseline.

Statistical Features + XGBoost: A more advanced approach using linguistic features.

Fine-tuned RoBERTa: A state-of-the-art deep learning method using a transformer-based model.

Ensemble Method: Combines the predictions of the three models using a majority vote mechanism for potentially improved accuracy.

Comprehensive Evaluation: Calculates and reports F1-score, precision, and recall for each individual strategy and the final ensemble model.

Modular Codebase: The project is structured into separate, well-documented files for clarity and reusability.

Setup and Installation
Clone the repository (or save all the files in a single directory).

Create a Python virtual environment (recommended):

python -m venv venv
source venv/bin/activate  # On Windows, use `venv\Scripts\activate`

Install the required dependencies:

pip install -r requirements.txt

Download NLTK data (for statistical features):
Run Python and enter the following commands:

import nltk
nltk.download('punkt')

How to Run the Project
Simply run the main script from your terminal:

python main.py

The script will execute the entire pipeline:

Download and preprocess the HC3 dataset (a smaller, balanced subset for efficiency).

Generate and save data visualizations in a new plots directory.

Engineer features for the machine learning models.

Train all three detection models and save them to a models directory.

Evaluate each model on the test set.

Perform an ensemble evaluation using a voting mechanism.

Print a final report comparing the performance (F1, Precision, Recall) of all strategies.

About the Models
Logistic Regression: A simple yet effective linear model that works on TF-IDF features to find patterns in word usage.

XGBoost: A powerful gradient-boosting model that uses statistical features like text length, perplexity, and linguistic complexity to make predictions.

RoBERTa: A large language model from the transformer family, fine-tuned on the specific task of distinguishing between human and AI text. It learns deep semantic patterns.

This project provides a solid foundation for further research into LLM text detection.
