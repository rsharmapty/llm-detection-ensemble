LLM-Generated Text Detection Project


![Hugging Face](https://img.shields.io/badge/%F0%9F%A4% hugging%20face-datasets-yellow)


This project provides a comprehensive framework and web application for detecting text generated by Large Language Models (LLMs). It performs a comparative analysis of different detection techniques on the HC3 (Human-ChatGPT Comparison Corpus) dataset and includes a web API for real-time inference.

✨ Features

Web Application: An easy-to-use web interface to paste text and get instant analysis from three different AI detection models.

Backend API: A Flask-based API that serves the trained models and provides predictions with confidence scores.

Multiple Detection Strategies: Implements and evaluates three distinct detection methods:

TF-IDF + Logistic Regression: A classic machine learning baseline.

Statistical & Semantic Features + XGBoost: An advanced approach using linguistic complexity and perplexity.

Fine-tuned RoBERTa: A state-of-the-art deep learning method using a transformer model.

Ensemble Method: Combines predictions using a majority vote for robust evaluation during the training phase.

Comprehensive Evaluation: Saves a detailed Excel report (evaluation_results.xlsx) with predictions for every text sample in the test set, perfect for error analysis.

Modular Codebase: The project is structured into separate, well-documented Python files for clarity and maintainability.

🚀 Setup and Installation

Clone the repository (or save all files to a single directory).

Create and activate a Python virtual environment (recommended):

python -m venv venv
source venv/bin/activate  # On Windows, use `venv\Scripts\activate`


Install the required dependencies:

pip install -r requirements.txt


Download NLTK data (for statistical features):
Run Python and enter the following commands to download the necessary package:

import nltk
nltk.download('punkt')


🏃 How to Run the Project

This is a two-step process. First, you must train the models. Then, you can run the web application.

Step 1: Train All Models

Run the main.py script from your terminal. This will execute the entire training and evaluation pipeline. You only need to do this once.

python main.py


This script will create the models/ directory and populate it with the trained Logistic Regression, XGBoost, and RoBERTa models, which are required for the web app to function.

Step 2: Run the Web Application

After the training is complete, start the Flask web server by running app.py.

python app.py


Once the server is running, open your web browser and navigate to:
https://www.google.com/search?q=http://127.0.0.1:5001

You can now paste any text into the web interface to get a real-time analysis from all three models.
